# Как поставить Zuno на iPhone с компьютера Windows

Инструкция для шагов i.5 и дальше. Решение и причины описаны в
[ADR 0009](decisions/0009-iphone-without-mac.md); здесь только порядок действий.

Как этим пользоваться: делайте шаги по одному, сверху вниз. У каждого шага написано, что
должно появиться на экране. Если появилось что-то другое и подсказки нет, остановитесь и
покажите экран ассистенту (Claude Code). Ничего не «пробуйте наугад».

Надписи на iPhone даны так, как в русской iOS. Sideloadly работает на английском, поэтому его
надписи даны по-английски; iTunes и GitHub — как в программе. Места с пометкой **(сверить в i.5)**
взяты из документации: при первой установке (шаг i.5) мы проверим их на вашем экране и
поправим инструкцию.

## Что понадобится

- Компьютер с Windows 11 и доступом в интернет.
- Кабель USB для iPhone (лучше оригинальный или тот, которым вы заряжаете телефон и который
  передаёт данные). **Для первого подключения кабель обязателен**: по Wi-Fi iPhone виден только
  после того, как его один раз подключили кабелем и включили синхронизацию по Wi-Fi в iTunes
  (раздел 5). Разъём на iPhone 15 и новее — USB-C, на более старых — Lightning.
- iPhone, его код-пароль (код разблокировки экрана). Подходит и iOS 27: команда Sideloadly
  подтвердила работу на ней в июле 2026.
- Apple ID (учётная запись Apple: адрес почты и пароль). Платный аккаунт разработчика не нужен.
- iPhone или другое устройство Apple под рукой: на него придёт 6-значный код двухфакторной
  проверки (второй шаг входа, кроме пароля).
- Около часа на первый раз. Дальше каждое обновление — 5–10 минут вашего времени плюс
  15–25 минут ожидания облачной сборки.

Несколько слов, которые встретятся дальше:

- **.ipa** — файл приложения для iPhone (как `.apk` на Android).
- **Подпись** — отметка Apple, без которой iPhone не запустит приложение. Sideloadly ставит её
  вашим Apple ID. Бесплатная подпись действует 7 дней.
- **Bundle id** — внутреннее имя приложения для iOS. У Zuno это `com.tonyvinsenty.zuno`. По нему
  iPhone понимает, что новая сборка — обновление старой, а не другое приложение.
- **Sideloadly** — программа для Windows, которая подписывает `.ipa` и ставит его на iPhone по
  кабелю.

## Главное: правила сохранности данных

> **Данные Zuno живут только на iPhone.** Сервера нет. Если нарушить правила ниже, данные можно
> потерять безвозвратно.
>
> 1. **Всегда Sideloadly и всегда один и тот же Apple ID.** Другой Apple ID или другая программа
>    (например, AltStore) = для iPhone это другое приложение.
> 2. **В Sideloadly ничего не менять в Advanced Options**, особенно bundle id. Единственное
>    исключение — флажок автопереподписи (раздел 5).
> 3. **Обновлять только установкой поверх. Приложение Zuno не удалять** — ни при обновлении, ни
>    когда оно перестало открываться. Удаление стирает все данные.
> 4. **Перед каждой установкой — экспорт CSV** и файл вне телефона (Telegram «Избранное»,
>    почта, компьютер). Обязательно начиная с шага i.7, когда экспорт заработает на iPhone. До
>    этого на iPhone вносим **только тестовые** операции.
> 5. **Появилась вторая иконка Zuno — остановиться**, старую не удалять (раздел 7).
> 6. Sideloadly предлагает что-то непонятное с Apple ID или сертификатом (например, «revoke»,
>    отозвать) — **остановиться и спросить ассистента**.
>
> **Apple ID для Zuno: ____**
>
> Репозиторий на GitHub публичный: полный адрес почты сюда не пишите. Достаточно подсказки,
> по которой вы сами узнаете учётную запись (например, «основной» или «отдельный, на g…»).

**Какой Apple ID выбрать.** Подойдёт ваш основной (рекомендуем: он у вас навсегда) или
отдельный, созданный для этого. Главное — потом **всегда тот же**. Apple ID в Sideloadly не
обязан совпадать с тем, под которым вошёл iPhone. Sideloadly отправляет пароль только на
серверы Apple. Ассистенту пароль не сообщайте никогда.

## 1. Подготовка компьютера

Sideloadly работает только с iTunes и iCloud, скачанными **с сайта Apple**. Версии из
Microsoft Store ему не подходят. Поэтому сначала убираем то, что могло встать из Store.

1. Откройте «Пуск» → «Параметры» → «Приложения» → «Установленные приложения». В поиске по
   очереди наберите `iTunes`, `iCloud`, `Apple Devices`, `Apple Music`, `Apple TV`.
   - Должно появиться: «Ничего не найдено» по каждому слову — тогда переходите к шагу 3.
   - Если что-то нашлось: шаг 2.
2. У каждого найденного нажмите «...» справа → «Удалить» → ещё раз «Удалить». Данные в облаке
   iCloud при этом не пострадают.
   - Должно появиться: приложение пропало из списка.
3. Скачайте iTunes с сайта Apple по ссылке https://www.apple.com/itunes/download/win64
   - Должно появиться: браузер скачивает файл `iTunes64Setup.exe`. Microsoft Store **не**
     открывается.
   - Если открылся Microsoft Store: закройте его, ничего там не ставьте, покажите ассистенту.
4. Запустите `iTunes64Setup.exe`. На вопрос Windows «Разрешить этому приложению вносить
   изменения?» нажмите «Да». В установщике нажимайте «Далее» → «Установить» → «Завершить»
   (у кнопок могут быть немного другие названия).
   - Должно появиться: iTunes установлен, на рабочем столе или в «Пуске» есть iTunes.
5. Скачайте iCloud по ссылке, которую даёт сайт Sideloadly:
   https://updates.cdn-apple.com/2020/windows/001-39935-20200911-1A70AA56-F448-11EA-8CC0-99D41950005E/iCloudSetup.exe
   Это старая версия 2020 года с серверов Apple — так и нужно.
   - Должно появиться: скачан файл `iCloudSetup.exe`.
6. Запустите `iCloudSetup.exe`, установите (кнопки «Да», «Установить», «Готово»). Если
   установщик попросит перезагрузить компьютер — перезагрузите.
   - Должно появиться: установка завершена, установщик предлагает перезагрузить компьютер —
     перезагрузите. После перезагрузки само откроется окно входа в iCloud: входить не нужно,
     просто закройте его.
7. Скачайте Sideloadly **только с официального сайта**:
   https://sideloadly.io/SideloadlySetup64.exe (сейчас версия 0.70.1).
   - Должно появиться: скачан файл `SideloadlySetup64.exe`.
8. Запустите `SideloadlySetup64.exe` и установите с настройками по умолчанию.
   - Должно появиться: Sideloadly установлен, есть ярлык.
   - Если Windows показала синее окно «Windows защитил ваш компьютер»: нажмите «Подробнее» →
     «Выполнить в любом случае». Так бывает с программами, которые Windows видит редко.
9. Подключите iPhone к компьютеру кабелем и разблокируйте его.
   - Должно появиться: на iPhone окно «Доверять этому компьютеру?».
   - Если окна нет: отключите и снова подключите кабель, держа iPhone разблокированным.
10. На iPhone нажмите «Доверять» и введите код-пароль iPhone.
    - Должно появиться: окно закрылось, iPhone заряжается.
11. Запустите iTunes. Если он спросит про лицензию — «Принимаю». Если спросит «Разрешить этому
    компьютеру доступ к информации на iPhone?» — «Продолжить».
    - Должно появиться: слева вверху в iTunes маленький значок iPhone. Значит, iTunes видит
      телефон. Это нужно сделать до первого запуска Sideloadly.
    - Если значка нет: см. «Частые проблемы», строка «Sideloadly или iTunes не видит iPhone».

Компьютер готов. Этот раздел делается один раз.

## 2. Первая установка

Нужен файл `.ipa` из облачной сборки (шаг i.3 или раздел 4, шаги 3–8). Имя файла вида
`Zuno-0.1.0-11.ipa`.

1. Подключите iPhone кабелем, разблокируйте. Запустите Sideloadly.
   - Должно появиться: окно Sideloadly. В списке устройств (поле **iDevice**) — имя вашего
     iPhone.
   - Если там `<no devices detected>`: iPhone не виден, см. «Частые проблемы».
2. В поле **Apple ID** введите свой Apple ID (адрес почты).
   - Должно появиться: адрес в поле. Впишите подсказку о нём в строку «Apple ID для Zuno» в
     блоке правил выше.
3. Перетащите файл `.ipa` мышью на большой значок **IPA** слева (или нажмите на значок и
   выберите файл).
   - Должно появиться: Sideloadly показал имя приложения Zuno (сверить в i.5).
4. **Advanced Options не трогайте.** Если раздел уже раскрыт, проверьте: режим подписи
   **Apple ID Sideload**, а в поле **Bundle ID** (если оно видно) — `com.tonyvinsenty.zuno`.
   - Если в поле Bundle ID что-то другое: не нажимайте Start, покажите экран ассистенту.
   - Автопереподпись можно включить уже сейчас (раздел 5, шаг 2) или при следующей установке.
5. Нажмите **Start**.
   - Должно появиться: окно с просьбой ввести пароль Apple ID (сверить в i.5).
6. Введите пароль Apple ID и подтвердите (**OK**).
   - Должно появиться: окно для 6-значного кода, а на iPhone (или другом устройстве Apple) —
     запрос на вход с Apple ID.
   - Если окно кода не появилось: у вашего Apple ID нет двухфакторной проверки, просто
     переходите к шагу 8.
7. На iPhone нажмите «Разрешить», посмотрите код и введите его в окно Sideloadly
   (сверить в i.5).
   - Должно появиться: в журнале внизу окна Sideloadly бегут строки, идёт прогресс.
   - Если код не приходит или окно кода появляется второй раз: закройте Sideloadly, обновите
     его до последней версии с sideloadly.io и начните с шага 1.
8. Дождитесь конца установки (обычно 1–3 минуты). iPhone не отключайте.
   - Должно появиться: в журнале последняя строка **Done.**
   - Если ошибка или вопрос про сертификат (revoke): ничего не нажимайте, покажите ассистенту.
9. Посмотрите на iPhone.
   - Должно появиться: иконка Zuno на экране «Домой» (может быть на последней странице).
   - Если иконки нет: перезагрузите iPhone.
10. Откройте Настройки → «Конфиденциальность и безопасность», прокрутите вниз до раздела
    «Безопасность» → «Режим разработчика». Этот пункт появляется только после первой установки
    приложения через Sideloadly. На iOS 15 его нет — тогда переходите к шагу 14.
    - Должно появиться: экран с переключателем «Режим разработчика».
11. Включите переключатель.
    - Должно появиться: предупреждение, что режим снижает безопасность, и кнопка «Перезапустить».
12. Нажмите «Перезапустить». После перезагрузки разблокируйте iPhone.
    - Должно появиться: окно с предложением включить режим разработчика.
13. Нажмите «Включить» и введите код-пароль iPhone.
    - Должно появиться: окно закрылось. Режим разработчика включён один раз и навсегда.
14. iPhone должен быть в интернете. Откройте Настройки → «Основные» → «VPN и управление
    устройством».
    - Должно появиться: раздел «Приложение разработчика», в нём ваш Apple ID.
15. Нажмите на свой Apple ID → «Доверять „<ваш Apple ID>“» → в окне ещё раз «Доверять».
    - Должно появиться: на экране написано, что приложения этого разработчика проверены, и
      видно Zuno. Это делается один раз для этого Apple ID.
16. Откройте Zuno.
    - Должно появиться: «Главная» Zuno. В категориях 14 штук.
    - Если «Ненадёжный разработчик»: не сделан шаг 15.
    - Если iOS пишет, что нужен режим разработчика: не сделаны шаги 10–13.

Готово. На шаге i.5 вносим только 2–3 **тестовые** операции и проверяем установку поверх
(раздел 4). Настоящие траты — только после шага i.7.

## 3. Что бывает с данными

iOS хранит данные приложения в отдельной «коробке» (контейнере), привязанной к bundle id. Новая
сборка с тем же bundle id и тем же Apple ID ставится поверх, коробка остаётся.

| Что случилось | Что с данными |
|---|---|
| Новая сборка поставлена поверх: Sideloadly, тот же Apple ID, тот же bundle id | **сохраняются** |
| Прошло 7 дней, подпись истекла | **сохраняются**; приложение не открывается, пока не переподпишете |
| Переподпись или установка той же сборки заново | **сохраняются** |
| Сертификат отозван | **сохраняются**; приложение не открывается, пока не поставите поверх заново |
| iOS «сгрузила» приложение | **сохраняются**; вернуть установкой поверх через Sideloadly |
| В Sideloadly изменён bundle id или установка сделана другой программой | **вторая иконка Zuno с пустой базой**; старые данные в старой копии (раздел 7) |
| Сборка подписана другим Apple ID | поверх не встанет; придётся удалить старое — **данные потеряны**, если нет CSV |
| Приложение удалено | **данные удалены** |

Ещё два момента:

- **«Сгружать неиспользуемые».** Лучше выключить: Настройки → «App Store» → «Сгружать
  неиспользуемые» (сверить в i.5). Если iOS всё же сгрузила Zuno (у иконки облачко), не
  удаляйте её, а поставьте `.ipa` поверх через Sideloadly.
- **Резервная копия iCloud** остаётся включённой, но восстановление данных приложения, которое
  поставлено не из App Store, **не гарантировано**. Главная копия — файл CSV.

## 4. Как поставить обновление

Короткий чек-лист: экспорт CSV → +1 к номеру → облачная сборка → скачать `.ipa` → поставить
поверх → проверить.

1. **Экспорт CSV.** Обязателен начиная с шага i.7. До i.7 экспорт на iPhone не работает (кнопка
   ничего не делает), данные там тестовые, пункт пропускаем.
   В Zuno: вкладка «Настройки» → «Экспорт в CSV» → в окне «Поделиться» выберите Telegram →
   «Избранное» → отправить (точные надписи окна сверим в i.7).
   - Должно появиться: в Telegram в «Избранном» файл с расширением `.csv`.
2. Попросите ассистента: «подними номер сборки и отправь на GitHub». Ассистент прибавит 1 к
   числу после «+» в `pubspec.yaml` (например, `0.1.0+11` → `0.1.0+12`), сделает коммит и
   `push`. Без вашей прямой просьбы он `push` не делает.
   - Должно появиться: ассистент пишет новый номер и что `push` выполнен.
3. Откройте https://github.com/TonyVinsenty/money_app (вы должны быть вошедшим в GitHub) →
   вкладка **Actions** вверху.
   - Должно появиться: список запусков, слева — список workflow (сценариев сборки).
4. Слева нажмите **iOS build**.
5. Справа нажмите **Run workflow**. В выпадающем окне ветка **main** → зелёная кнопка
   **Run workflow**.
   - Должно появиться: через несколько секунд в списке новая строка с жёлтым кружком (идёт
     сборка). Если строки нет — обновите страницу.
6. Ждите 15–25 минут. Страницу можно закрыть и вернуться позже.
   - Должно появиться: у строки зелёная галочка.
   - Если красный крестик: откройте запуск и покажите ассистенту (это ошибка сборки, её правит
     разработчик).
   - Если запуск долго висит в очереди (Queued) или в журнале ошибка
     «The job was not acquired by Runner»: это сбой на стороне GitHub, не наш код. Откройте
     https://www.githubstatus.com — там видно, есть ли проблемы с Actions. Подождите и
     запустите снова (шаг 5).
7. Нажмите на строку с зелёной галочкой и прокрутите страницу вниз до раздела **Artifacts**.
   - Должно появиться: файл `Zuno-0.1.0-12.ipa` (номер — новый, из шага 2).
8. Нажмите на него, чтобы скачать. GitHub хранит его 14 дней, поэтому **последний `.ipa`
   держите на компьютере** (он нужен для переподписи, раздел 5).
   - Должно появиться: в «Загрузках» файл `.ipa`.
   - Если скачался `.zip`: распакуйте, внутри будет `.ipa`.
9. Поставьте `.ipa` **поверх** так же, как в разделе 2, шаги 1–8: тот же Apple ID, Advanced
   Options не трогать (автопереподпись — как в прошлый раз). Zuno перед этим **не удалять**.
   Режим разработчика и доверие (шаги 10–15) повторять не нужно.
   - Должно появиться: в журнале Sideloadly **Done.**
10. Проверьте результат.
    - Откройте Zuno: операции на месте.
    - Иконка Zuno **одна**. Проверьте и в «Библиотеке приложений» (последний экран справа),
      набрав в поиске «Zuno».
    - Версия: Настройки → «Основные» → «Хранилище iPhone» → Zuno (сверить в i.5). Там видно
      только `0.1.0`, число после «+» iOS здесь, скорее всего, не показывает; новый номер
      подтверждает имя файла из шага 7.
    - Если иконок две: раздел 7.

## 5. Переподпись раз в 7 дней

Бесплатная подпись живёт 7 дней с момента установки. Потом Zuno не открывается (iOS пишет, что
приложение больше недоступно или его нельзя проверить, сверить в i.5). **Данные при этом
целы. Приложение не удалять.**

Совет: поставьте себе напоминание в календаре на 6-й день после каждой установки.

**Переподпись вручную** (надёжный способ):

1. Поставьте **последний** `.ipa` поверх, как в разделе 4, шаг 9. Новая сборка в облаке для
   этого не нужна.
   - Должно появиться: **Done.**, Zuno открывается, данные на месте. Новые 7 дней пошли.

**Автопереподпись (auto-refresh)**: Sideloadly сам переподписывает приложение в фоне до
истечения 7 дней. Её служба называется Sideloadly Daemon. Условия: компьютер включён, служба
Sideloadly запущена, iPhone подключён кабелем или в той же сети Wi-Fi, экран iPhone лучше
разблокирован.

2. При установке (раздел 2, шаг 4) раскройте **Advanced Options** и включите флажок
   автоматической переподписи (точное название сверить в i.5; возможно, это синий значок с
   круговыми стрелками слева от кнопки **Start**). Больше ничего там не меняйте.
   - Должно появиться: после **Done.** приложение отмечено для автопереподписи (как это видно —
     сверить в i.5).
3. Чтобы работало без кабеля: подключите iPhone кабелем, в iTunes нажмите значок iPhone →
   страница «Обзор» → включите «Синхронизировать с этим iPhone по Wi-Fi» → «Применить».
   - Должно появиться: после отключения кабеля iPhone по-прежнему виден в iTunes и в
     Sideloadly, когда компьютер и телефон в одной сети Wi-Fi.
   - Если по Wi-Fi не виден: служба Apple Bonjour (ставится вместе с iTunes) должна работать;
     покажите ассистенту.

Автопереподпись — удобство, а не гарантия. Напоминание в календаре всё равно оставьте.

## 6. Лимиты бесплатной подписи

- Подпись действует **7 дней** (раздел 5).
- Одновременно не больше **3 приложений**, поставленных так одним Apple ID. Если у вас есть
  другие такие приложения и Zuno не встаёт — удалять можно только **другие**, не Zuno.
- Не больше **10 App ID за 7 дней** (App ID — регистрация bundle id у Apple). Установка Zuno
  поверх с тем же bundle id новый App ID не тратит. Ошибка «maximum App ID limit» — подождите
  7 дней. **Apple ID ради Zuno не меняйте** (потеря данных, раздел 3).
- Возможности с особыми правами (iCloud в приложении, push-уведомления) бесплатной подписи
  недоступны. Zuno они не нужны.

## 7. Появилась вторая иконка Zuno

Значит, iPhone принял сборку за другое приложение (другой bundle id или другая программа). У
новой копии пустая база, ваши данные — в старой.

1. **Остановитесь. Ни одну копию не удаляйте.**
2. Откройте обе по очереди. Старая — та, где ваши операции.
3. В старой сделайте экспорт CSV (раздел 4, шаг 1). До шага i.7 экспорт не работает — тогда
   пропустите этот пункт, данные пока тестовые.
4. Покажите ассистенту, что случилось: какой файл ставили и с какими настройками Sideloadly.
   Что удалять и как поставить правильно, решаем вместе.

## 8. Частые проблемы

| Что видно | Что делать |
|---|---|
| Sideloadly или iTunes не видит iPhone | разблокировать iPhone и нажать «Доверять»; другой кабель или порт USB; удалить iTunes и поставить заново с сайта Apple (раздел 1) |
| Ошибка со словами Lockdown или NP_E_CONN_FAILED | стоит iTunes из Microsoft Store: удалить его, поставить с сайта Apple (раздел 1, шаги 1–4) |
| Sideloadly пишет, что не нашёл iTunes | то же: iTunes и iCloud нужны с сайта Apple (раздел 1) |
| Код двухфакторной проверки не приходит или окно кода появляется дважды | обновить Sideloadly до последней версии с sideloadly.io и повторить |
| Sideloadly предлагает отозвать (revoke) сертификат или спрашивает непонятное про Apple ID | остановиться, показать ассистенту. Отзыв данные не стирает, но Zuno не откроется до установки поверх |
| Ошибка «maximum App ID limit» | подождать 7 дней; Apple ID не менять (раздел 6) |
| После установки нет иконки Zuno | перезагрузить iPhone |
| При запуске «Ненадёжный разработчик» | доверить свой Apple ID (раздел 2, шаги 14–15) |
| iOS пишет, что нужен режим разработчика | включить его (раздел 2, шаги 10–13) |
| Zuno перестал открываться через неделю | истекла подпись: поставить последний `.ipa` поверх (раздел 5). Не удалять |
| У иконки Zuno облачко | iOS сгрузила приложение: поставить `.ipa` поверх (раздел 3) |
| Две иконки Zuno | раздел 7 |
| Облачная сборка висит в очереди или «The job was not acquired by Runner» | сбой GitHub: проверить githubstatus.com, подождать, запустить снова (раздел 4, шаг 6) |
| Облачная сборка с красным крестиком | показать ассистенту журнал запуска |
| В Artifacts нет файла | запуск не зелёный или прошло больше 14 дней: запустить сборку заново (раздел 4, шаг 5) |
