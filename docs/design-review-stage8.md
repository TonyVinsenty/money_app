## 1. Вердикт и топ-10

Приложение собрано на одной системе оформления. Отступы по шкале, суммы читаются, цвет почти везде только у смысла, в тёмной теме и при скрытых суммах проблем не нашёл. Ощущение «незаконченности» создают две вещи:
- компоненты темы, оставленные по умолчанию Material: сообщение снизу (SnackBar), сегменты, меню, шапка при прокрутке, календари;
- разнобой в похожих местах: строки выбора в формах, шрифты строк категорий, кнопки удаления.

Почти всё правится в теме (`lib/core/ui/theme/app_theme.dart`) и в 3–4 общих виджетах, без пакетов.

Топ-10:
1. D1. Сообщение снизу должно быть плавающим, со скруглением и зазором над капсулой.
2. D2. Выбранный сегмент показывать акцентом. Сейчас выбранный выглядит бледнее невыбранного.
3. D3. «Главная» на узком и коротком экране: легенда уходит за край, месяц мелкий.
4. D6. Одно «поле выбора» во всех формах вместо пяти разных видов.
5. D7. Одни шрифты для строк категорий во всей «Аналитике».
6. D5 (iPhone). Дата выбирается колесом, как время, а не Material-календарём.
7. D10. Шапка экранов при прокрутке не должна голубеть.
8. D8. Лист фильтра: кнопка «Готово» закреплена внизу, порядок «Все · Расходы · Доходы».
9. D12. Удаление и архив в редакторах: одно место и один цвет.
10. D9, D19, D20. Точка фильтра акцентом вместо красного, «6 октября» без «2026 г.», заголовки дней с заглавной буквы.

**Где.** «Настройки» → группа «О приложении», вторая строка после «Информации о разработчике»:

**Экран «Спасибо»** (сверху вниз):
1. Шапка «Спасибо» с кнопкой «Назад».
2. Маленький знак Zuno (кольцо, 48 dp) по центру. Под ним одна фраза bodyMedium цветом onSurfaceVariant по центру. Тексты на выбор — ниже.
3. **«Соавторы»** — подзаголовок группы по 8.4: titleSmall, 600, цвет акцента, отступ сверху 24. Под ним карточка в рамке, радиус 16, поля 16; в ней по одному имени на строку, titleMedium 500, строки по 48 dp, без аватаров и значков. Рамка карточки выделяет старший уровень без всяких слов.
4. **Второй блок** (название на выбор) — тот же стиль подзаголовка. Имена идут сплошным абзацем через « · »: bodyLarge, межстрочный 1,5, без карточки. Технически это `Wrap` из отдельных `Text`; точки-разделители убраны из озвучки.
5. Порядок имён — как в файле. Пользователь сам решает: по дате поддержки или по алфавиту.

**Количество имён:**
- **0.** Строка «Спасибо» в «Настройках» не показывается совсем. Пустой экран с призывом читался бы как просьба о деньгах.
- **Пусто только в одном блоке** — этот блок вместе с подзаголовком скрыт.
- **3 имени.** Экран короткий, содержимое прижато к верху, ничего не растягиваем.
- **200 имён.** Абзац примерно на 40 строк при 100 % и на 100 строк при 200 %. Экран прокручивается, «Соавторы» всегда вверху. Счётчиков вида «и ещё 180» нет.

**Крупный шрифт и узкий экран.** Каждое имя — отдельный элемент `Wrap`, поэтому имя не рвётся посередине. Длинное имя из нескольких слов переносится по словам. Слово шире экрана — `FittedBox` уменьшает его, как в 8.6.

**Скринридер.** Подзаголовки помечены как заголовки (`header: true`), имена читаются по одному. «Скрыть суммы» на экран не влияет. Тёмная тема — те же роли цветов.

**Данные.** Файл `assets/thanks.json` вида `{"coauthors": [...], "friends": [...]}`. Читается через `rootBundle`, без пакетов. Тест: при пустом файле строки нет; при 3 и при 200 именах экран строится без переполнения при 200 %.
